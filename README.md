# SmartProxy v0.8 Integration Beta

این نسخه، رابط مرجع فارسی v0.7 را با موتور واقعی v0.3 در یک پوشه تجمیع کرده است. دریافت منابع HTTPS و URIهای دستی، خواندن و نمایش کانفیگ‌های واقعی، تولید پیکربندی و فرمان اتصال/قطع واقعی از طریق CLI موجود انجام می‌شود. **این نسخه برای استفاده روزمره تأیید نشده**، و اتصال ممکن است به علت نبود sing-box، polkit یا سرویس systemd شکست بخورد. انتخاب خودکار، تشخیص کشور سرورها، به‌روزرسانی یام‌یام از صفحه وب، فیلترهای تصویر مرجع و Failover واقعی هنوز کامل نیستند. تصویر زمینه حاوی نمونه‌های تزئینی است و جایگزین فهرست واقعی نیست.

## اجرا

```bash
cd smartproxy-ui-v0.8-integration-beta
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python main.py
```

صفحه وب یام‌یام لینک Subscription معتبر نیست؛ باید آدرس مستقیم خروجی قابل پشتیبانی وارد شود. از اجرای Start روی سیستم دارای اتصال SSH ضروری بپرهیزید.
